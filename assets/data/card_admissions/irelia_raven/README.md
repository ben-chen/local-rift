# Ravenbloom Prefect

The complete original VEN-102/166 face was inspected November 11, 2026. Its
single official printing agrees with the archived gallery: Chaos Unit, 3 Energy,
no Power, 3 Might, Noxus. No listed erratum or printing conflict applies. The
admission preserves the raw/effective facts, full image, client art and hashes of
the preceding 424 main cards and five exact presets.

When an opponent completes a gear play, including a Gold token, this unit offers
an optional cost. Banish the physical source before the ability becomes
respondable (Core 204.1.c and 404.1.b.1). Declining retains the unit. Banish is not
Kill: it does not invoke Deathknell or Guardian Angel/Hourglass death replacements.
The finalized ability persists after its source leaves and banishes only the
original event gear if it remains in play. A replacement copy is a different
object. The gear is an event subject, not a chosen target; Not So Fast's chosen
friendly-object restriction therefore does not counter this ability.

The native panel and bot API expose the same accept/decline choice and source
identity. The AI compares the public gear value with keeping the unit, including
its current Might, readiness and battlefield scoring position. Beginner and
Advanced commentary explain the cost and response tradeoff. The card is available
for custom decks; the original sourced recipes are unchanged. This does not add
best-of-three sideboarding.
