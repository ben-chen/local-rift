# Edge of Night — admission evidence

Runtime card 432 is the single accepted SFD-139/221 printing. Its full original
744×1039 official face was inspected, and the 280-pixel runtime art is pinned
separately in `admissions.json`. It is Chaos Gear / Equipment, costs 3 Energy,
gives +2 Might while attached, and has Hidden and Equip for one Chaos Power.

The [Spiritforged erratum](https://playriftbound.com/en-us/news/rules-and-releases/riftbound-spiritforged-errata/)
changes literal “here” to reminder “(here)”. The
[official FAQ](https://playriftbound.com/en-us/news/rules-and-releases/riftbound-spiritforged-faq/)
explains why: unattached gear returns to base during cleanup while its attachment
ability waits. Hidden still restricts that ability to the original battlefield.
The raw printed text and image remain separate from the operative erratum.
No existing source correction or alternate-printing review changes.

Hand play and paid Equip, Hidden play and delayed attachment, moved/departed
targets, source departure, Orianna’s gear condition and Irelia’s choose/ready
interactions have focused coverage. An opponent’s Not So Fast cannot counter
this attachment when it chooses only the controller’s unit; that test verifies
rejection of an illegal counter. Beginner and Advanced coaching use visible state.
