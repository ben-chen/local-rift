# C13 gear interactions: ten source admissions

Reviewed October 24, 2026. The admission record preserves complete raw and effective facts, direct visual observations, original artwork and runtime thumbnails for IDs 362–371: Detonate, Thermo Beam, Brittle Steel, Decree of Unity, Disarming Rake, Stalwart Goatherd, Noxian Demolitionist, Adaptatron, Dropboarder and Production Surge. All ten are single-print Standard-legal identities in the dated inventory, without indexed errata or unresolved source fields. None adds a chosen champion.

The original PNGs total 8,216,520 bytes. Nine are archived here; Goatherd reuses its prior source-review image and the separately corrected Mount Targon tag. Its raw empty tags remain preserved. The ten runtime images total 2,556,762 bytes and each is below 300 KB. Official artwork and credited illustrators remain Riot Games property.

Patched Porobot is excluded. Its source review establishes that it is both Unit and Gear, but the runtime does not yet implement a physical object with both types. Neither its corrected source facts nor these ten admissions make it playable.

The existing 362 runtime cards, four presets, eight training recipes, legend registry, 117 field resolutions, 73 raw records/images, 42 historical issue groups, and 29 identity reviews covering 90 variant printings are pinned. This expansion yields 372 main cards and 397 mapped legal identities, with 682 of 1,079 legal identities still unavailable. Tests keep earlier source-only and C12 gameplay checkpoints as historical snapshots.

The gameplay tests separately cover gear targets and locations, live Might limits, simultaneous destruction, linked draws, actual-kill Buff, event-time ready conditions, Flow, Mech costs, pending token children, and exact bot actions.
